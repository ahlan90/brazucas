Acesso ao GitHub Desconectado

Para publicar, este navegador precisa de um token do GitHub com permissão de escrita só neste repositório. O token fica salvo apenas aqui, neste navegador. Não use em computador compartilhado.

  1. Abra GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Em Repository access, escolha Only select repositories e marque o repositório do site.
  3. Em Permissions → Repository permissions, coloque Contents: Read and write. Nada mais.
  4. Gere, copie o token e cole abaixo.

Publicar semana

Selecione as linhas da planilha (pode incluir o cabeçalho), copie e cole abaixo. A ordem das colunas é a mesma da planilha: posição, nome, poder, classe, conquista, dungeon, fenda, torre, provação e disputa. A coluna de seta (↑2, ↓1, N) é opcional.

Fotos dos personagens

Clique num membro e escolha a imagem. Ela é cortada em quadrado e substitui a foto atual. Dica: tire um print do personagem no jogo. Também dá para trocar a foto pelo ícone de câmera no próprio site, quando este navegador está conectado.
